# v0.14.0

> 横屏适配、内核选择界面与三项体验增强：护眼调光、底部导航栏滑动切换标签、
> 标签中键关闭。

## 新增

- **横屏适配**
  - 紧凑布局判定同时考虑宽高：宽度 < 720dp，或横屏且高度 < 560dp，
    都按紧凑布局排放，避免横屏下顶栏堆叠把内容区挤到几乎不可见。
  - 横屏且启用底部导航栏时，改用左侧竖排导航（后退 / 前进 / 主页 /
    工具箱 / 菜单），垂直空间完整留给网页。
  - 设置页与内核管理页在宽度 ≥ 780dp 时居中限宽 780dp。
- **屏幕方向锁定**：外观页新增「跟随系统 / 锁定竖屏 / 锁定横屏」，
  选择持久化并在启动与切换时立即生效。
- **内核管理页**：设置页的「浏览器内核」卡片可进入独立管理页，列出平台
  默认、系统/内置内核、独立内核包与插件携带内核；支持切换、安装 `.zbk`
  内核包、卸载独立内核包，并展示不可用原因与目录篡改告警。切换只影响
  新建标签页，页面内已注明。
- **护眼调光**：全界面黑色遮罩，强度 0–60% 可调（外观页滑块），主菜单
  「护眼调光」一键在 0 与 35% 间切换；遮罩不拦截触摸，浮层对话框不受
  影响。
- **底部导航栏滑动切换标签**：左下/右下轻扫切换上一个/下一个标签页。
- **标签中键关闭**：桌面平台在标签块上按鼠标中键即关闭该标签。

## 说明

- 方向锁定调用 `SystemChrome.setPreferredOrientations`，桌面平台为空操作。
- 新增单元测试 `test/orientation_and_dimmer_test.dart`：方向解析、持久化、
  调光强度边界（0–0.6）。
