# v0.13.0

> 界面统一 Material 3 / Google 风格，Windows 支持莫奈取色，新增应用内页面
> 调试面板，并提供网页访问优化、网页字体分离与后台标签休眠。

## 新增

- **Windows 莫奈取色**：新增「系统取色」（读取系统强调色）与「壁纸取色」
  （从当前桌面壁纸提取主色，失败回退强调色）两种取色源，在
  设置 → 外观 → 莫奈取色中切换；取色结果与 HCT 莫奈引擎联动生成全套配色。
- **页面调试面板**（设置 → 内容与安全 → 允许开发者工具，默认关闭）：
  - 控制台：实时显示 `console.*`、未捕获异常与 Promise 拒绝；
  - 网络：记录 `fetch` / `XMLHttpRequest` 的方法、URL、状态码与耗时；
  - 执行 JS：输入表达式并回显结果；
  - 页面信息：URL / 标题 / 视口 / DPR / UA；
  - Windows 可一键打开 WebView2 原生 DevTools 窗口；F12 呼出面板。
- **网页访问优化**：注入 DNS 预取 / 预连接与首屏图片 `fetchpriority`
  提示，首屏外图片延迟加载，可在设置中整体关闭。
- **网页字体分离**：外观设置新增「网页字体」，可选跟随页面、与界面字体
  一致或自定义字族；注入样式跳过 `pre` / `code` 与可编辑区域。
- **后台标签休眠**：空闲超过阈值且标签较多时卸载后台页面释放内存，
  切回时重新加载并恢复滚动位置与表单值；固定 / 隐私 / 前台标签不参与。

## 变更

- 主题层集中补齐 Material 3 组件样式（Chip、SegmentedButton、Checkbox、
  Radio、Slider、进度条、NavigationBar），并新增圆角设计令牌
  `ZbTokens.radius*`，各页面统一继承。
- 构建信息与关于页版本号更新至 0.13.0。

## 说明

- 调试面板的日志钩子在页面加载时注入；打开面板前的历史日志不会补录，
  重新加载页面或刷新后可看到完整输出。
- 后台标签休眠默认关闭，可在设置 → 性能中开启并调整空闲阈值。
