# Zip Browser v0.9.0 —— 广告拦截 / 性能优化 / 视觉打磨

本版本把 Zip Browser 推向「真正的浏览器」：内置广告拦截、补齐导航完成路径的性能短板、
修复移动端内存风险，并统一全局控件质感。

## ✨ 新功能

- **内置广告拦截（全新）**
  - 注入式拦截：documentStart 优先 hook `fetch` / `XMLHttpRequest`，命中广告域名直接拒绝；
  - 页面广告位隐藏：内置保守 CSS 选择器清单 + MutationObserver 节流清理动态广告；
  - 内置约 160 条广告 / 跟踪 / 弹窗域名（按国际 / 中文联盟 / 弹窗 / 视频分组）；
  - 设置页「内容与安全 → 广告拦截」开关 + **自定义拦截域名** + **白名单域名**编辑；
  - 主菜单新增「广告拦截」快捷开关（切换后自动刷新当前页生效）。
- 主菜单新增广告拦截开关项（与 JS 开关同组，切换即刷新生效）。

## 🚀 性能优化

- **导航完成并行化**：前进/后退能力查询、网页增强注入与站点缩放改为并行执行，
  页面加载完成后响应更快；
- **启动并行化**：缩放与会话两个服务并行初始化，缩短冷启动时间；
- **标签上限保护**：最多 32 个标签（移动端每个标签持有一个 WebView），
  超限时提示关闭部分标签，防止低端机内存耗尽。

## 🐛 Bug 修复

- 设置页底部版本号修正为动态读取（此前写死 0.5.0）；
- 广告域名表去除整域误伤（不再拦截 baidu.com / qq.com 等主站根域名）。

## 🎨 视觉打磨

- 新增全局滚动条主题（细圆角、主题色、桌面端更精致）；
- 延续 Firefox 风 UI：底部悬浮导航 dock、二级工具栏、OPPO Sans 内置字体。

## 📦 构建产物

- Android：按 ABI 拆包（armeabi-v7a / arm64-v8a / x86 / x86_64）+ 通用包；
- Windows：setup.exe 安装器 + zip；
- Linux：deb（amd64 / arm64）+ tar.gz（amd64 / arm64）；
- 独立内核包：chromium / gecko / lite 按平台拆分 .zbk。
