# Zip Browser v0.10.1 —— 修复启动卡死 / 无法启动

针对"无法启动、卡死"问题的修复版。

## 🔧 修复内容

1. **会话恢复不再卡死**：`restoreLastSession()` 由"全量串行创建 WebView"改为
   **最多恢复 16 个标签 + 每批 4 个并行创建** + 单个标签失败自动跳过 +
   全部失败自动兜底新建标签，并给每个标签 20 秒超时看门狗（内核死锁不再挂起启动）；
2. **首帧优先渲染**：首个标签创建移到首帧渲染完成后异步执行——启动立即出界面，
   不再长时间黑屏/停留在启动画面；
3. **全链路异常兜底**：
   - 莫奈取色失败静默降级（不再因平台通道异常中断启动）；
   - 初始标签创建失败自动兜底新建，绝不让应用停在空白；
4. **内核初始化失败显示错误页**：内核包与设备不匹配 / 内核损坏时，
   标签页显示内置错误页（提示切换回系统内核），而不是白屏假死；
5. 内核包损坏时创建标签自动回退系统内核（沿用）。

## 📦 构建产物

- Android：按 ABI 拆包（armeabi-v7a / arm64-v8a / x86_64）+ 通用包；
- Windows：setup.exe 安装器 + zip；
- Linux：deb（amd64 / arm64）+ tar.gz（amd64 / arm64）；
- 独立内核包：chromium / gecko / lite 按平台拆分 .zbk。
