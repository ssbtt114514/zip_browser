# 需求：UI 风格、网页体验与 Windows 平台能力（v0.13 批次）

## 背景

Zip Browser 已完成三风味内核与 Android 5.0 支持。本批次聚焦四类诉求：
界面统一为 Google 风格、网页访问与字体渲染体验、内存占用、以及
Windows 平台能力（系统莫奈取色、Edge 开发者工具）。用户表示「更多功能」
的具体清单后续补充，本文件先覆盖已确认范围。

## 功能需求

### R1 界面风格（Google / Material 3）

- R1.1 应用内所有页面的控件、间距、圆角、动效遵循 Material 3 规范
  （`useMaterial3: true` 已开启，需补齐不一致处）。
- R1.2 保留既有「Cupertino 风格」开关，Material 风格为默认。

### R2 莫奈取色（跨平台，含 Windows）

- R2.1 当用户选择「系统取色」时，Windows 使用系统强调色作为种子，
  经内置莫奈引擎生成 Material 3 配色。
- R2.2 当用户选择「壁纸取色」时，Windows 读取当前桌面壁纸并提取主色
  作为种子；提取失败时回退到系统强调色，再失败回退到手动种子色。
- R2.3 取色源在设置页可切换：系统强调色 / 壁纸取色 / 内置引擎（手动种子色）。
- R2.4 非 Windows 平台行为保持不变：Android 12+ 使用系统动态色板，
  其余平台走内置引擎。
- R2.5 平台取色失败必须静默降级，不影响启动。

### R3 开发者工具（Windows）

- R3.1 用户可以从菜单/快捷键打开页面开发者工具面板。
- R3.2 面板至少提供：控制台输出、执行 JS、页面信息、网络请求记录。
- R3.3 提供打开 WebView2 原生 Edge DevTools 窗口的入口。
- R3.4 非 Windows 平台不展示该入口。

### R4 网页访问与字体渲染优化

- R4.1 网页加载性能优化措施必须可开关或可回退。
- R4.2 字体渲染：支持自定义字体已存在（`FontService`），需保证设置项
  明确生效范围（界面字体 / 网页字体）。

### R5 内存占用

- R5.1 提供标签页休眠 / 后台页释放策略，降低多标签内存占用。
- R5.2 内存优化不得导致页面状态丢失后无法恢复。

## 非功能需求

- N1 所有平台取色/调色失败不得抛异常到 UI。
- N2 新逻辑需有单元测试；不得引入新的重量级依赖。
- N3 Android 5.0+ / Windows x64 / Linux x64+arm64 构建保持可用。
